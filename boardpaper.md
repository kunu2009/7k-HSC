## 1. English

### Paper Overview
| Aspect | Details |
|--------|---------|
| **Total Marks** | 80 (Theory) + 20 (Oral/Internal) = 100 |
| **Duration** | 3 Hours |
| **Sections** | 4 Sections |
| **Question Types** | Prose, Poetry, Grammar, Writing Skills |

### Section-wise Distribution

#### **Section I: Prose (Q.1)** - 16 Marks
| Q.No | Question Type | Marks | From |
|------|---------------|-------|------|
| 1(A)(i) | Read the extract and complete activities | 8 | Prose Lesson |
| 1(A)(ii) | Vocabulary | 2 | Given Extract |
| 1(A)(iii) | Personal Response | 2 | Extract Theme |
| 1(A)(iv) | Language Study (Grammar) | 4 | - |
| 1(B)(i) | Read the extract and complete activities | 8 | Different Prose |
| 1(B)(ii) | Vocabulary | 2 | Given Extract |
| 1(B)(iii) | Personal Response | 2 | Extract Theme |
| 1(B)(iv) | Language Study | 4 | - |

**Activity Types in Prose:**
- Complete the web/table/flow chart
- True/False
- Match the columns
- Choose the correct option
- Find from the passage
- Complete the statements
- Arrange in proper order/sequence

#### **Section II: Poetry (Q.2)** - 12 Marks
| Q.No | Question Type | Marks | From |
|------|---------------|-------|------|
| 2(A)(i) | Read the extract and complete activities | 4 | Poem |
| 2(A)(ii) | Personal Response | 2 | Poem Theme |
| 2(B)(i) | Read the extract and complete activities | 4 | Different Poem |
| 2(B)(ii) | Poetic devices/Appreciation | 2 | - |

**Poetry Activity Types:**
- Rhyme scheme identification
- Figures of speech (Simile, Metaphor, Alliteration, etc.)
- Theme identification
- Pick lines matching given meaning
- Complete the summary

#### **Section III: Writing Skills (Q.3 & Q.4)** - 28 Marks

##### Q.3: Writing Skills - 16 Marks
| Q.No | Question Type | Marks | Options |
|------|---------------|-------|---------|
| 3(A) | **Essay Writing** | 8 | 3 topics (Choose 1) |
| 3(B) | **Letter Writing** (Formal/Informal) | 4 | 2 options (Choose 1) |
| 3(C) | **Report Writing / Interview / Review / Appeal** | 4 | 2 options (Choose 1) |

**Essay Topics Usually From:**
- Current Affairs / Social Issues
- Science & Technology
- Environment
- Education
- Personal Experience
- Festivals / Culture

##### Q.4: Novel/Drama - 12 Marks
| Q.No | Question Type | Marks | From |
|------|---------------|-------|------|
| 4(A) | Complete the activities (Web/Table/Matching) | 4 | Novel - "The Sign of Four" |
| 4(B) | Answer in brief | 2 | Novel |
| 4(C) | Answer in brief | 2 | Novel |
| 4(D) | Answer in detail / Character sketch | 4 | Novel |

#### **Section IV: Genre - Drama (Q.5)** - 24 Marks
| Q.No | Question Type | Marks | From |
|------|---------------|-------|------|
| 5(A) | Complete activities based on extract | 4 | Drama - "The Rising of the Moon" |
| 5(B) | Answer in brief (2 marks each) | 4 | Drama |
| 5(C) | Answer in detail | 4 | Drama |

### Grammar Topics Tested
- Tenses (all types)
- Voice (Active/Passive)
- Narration (Direct/Indirect Speech)
- Clauses (Noun, Adjective, Adverb)
- Transformation of sentences
- Word formation (Noun/Verb/Adjective/Adverb)
- Spot the error

## 4. Political Science

### Paper Overview
| Aspect | Details |
|--------|---------|
| **Total Marks** | 80 (Theory) + 20 (Project) = 100 |
| **Duration** | 3 Hours |
| **Sections** | 4 Sections (Q.1-Q.8) |
| **Question Types** | MCQ, Short Answer, Long Answer, Correlation |

### Section-wise Distribution

#### **Q.1: Multiple Choice Questions (MCQs)** - 20 Marks
| Format | Details |
|--------|---------|
| Total MCQs | 20 (1 mark each) |
| Options | 4 options per question |
| Coverage | All chapters equally |
| Type | Factual, Conceptual, Analytical |

**MCQ Topics:**
- Definitions of key terms
- Important dates and events
- Names of leaders/thinkers
- Constitutional provisions
- Current affairs (Indian Politics)

#### **Q.2: Identify the Incorrect Pair / Odd One Out** - 4 Marks
| Format | Details |
|--------|---------|
| Questions | 2 (2 marks each) |
| Type | Find incorrect matching or odd item |

#### **Q.3: Complete the Concept Map / Web / Flow Chart** - 4 Marks
| Format | Details |
|--------|---------|
| Questions | 2 (2 marks each) |
| Type | Fill missing concepts in diagrams |

#### **Q.4: State Whether True or False with Reason** - 8 Marks
| Format | Details |
|--------|---------|
| Questions | 4 (2 marks each) |
| Type | True/False + Justification |

#### **Q.5: Answer in Brief (Short Answer)** - 16 Marks
| Format | Details |
|--------|---------|
| Questions | 4 out of 6 (4 marks each) |
| Word Limit | 50-80 words |
| Type | Explain concepts, define terms, causes/effects |

**Common Patterns:**
- "What is...?"
- "Define..."
- "State the features of..."
- "Give reasons for..."
- "Explain the significance of..."

#### **Q.6: Answer in Detail (Long Answer)** - 16 Marks
| Format | Details |
|--------|---------|
| Questions | 2 out of 4 (8 marks each) |
| Word Limit | 150-200 words |
| Type | Detailed explanation with examples |

**Common Patterns:**
- "Explain in detail..."
- "Discuss the role of..."
- "Critically analyze..."
- "Compare and contrast..."

#### **Q.7: Answer with Reference to the Given Points** - 8 Marks
| Format | Details |
|--------|---------|
| Questions | 2 (4 marks each) |
| Type | Structured answer using given sub-points |

#### **Q.8: 🔗 Correlation Questions** - 4 Marks
| Format | Details |
|--------|---------|
| Questions | 2 (2 marks each) |
| Type | **Find relationship between two concepts** |

**Correlation Question Examples:**
- "State the correlation between Sovereignty and State"
- "State the correlation between Democracy and Elections"
- "State the correlation between Federalism and Decentralization"
- "State the correlation between Legislature and Law-making"

**How to Answer Correlation:**
1. Define both concepts briefly
2. State the direct relationship
3. Explain how one affects/depends on the other
4. Give an example if possible

### Chapter-wise Important Topics

|---------|---------------------------|

## Implementation Plan

### 🎯 Phase 1: Chapter-Level Question Bank Structure

For each subject and chapter, we will create:

```
📁 Subject (e.g., Political Science)
├── 📁 Chapter 1
│   ├── 📋 MCQs (15-20 questions)
│   ├── 📋 True/False with Reason (5-8 questions)
│   ├── 📋 Short Answers - 4 marks (8-10 questions)
│   ├── 📋 Long Answers - 8 marks (4-6 questions)
│   ├── 🔗 Correlation Questions (for Pol.Sci/Eco)
│   ├── 📊 Concept Maps/Webs
│   ├── 📜 Previous Year Questions (2020-2025)
│   └── 💡 Important Definitions & Keywords
├── 📁 Chapter 2
│   └── ... (same structure)
```

### 🎯 Phase 2: Special Question Types by Subject

| Subject | Special Question Types |
|---------|----------------------|
| **Political Science** | 🔗 Correlation Questions, Constitutional Provisions |
| **History** | 🗺️ Map Work, Timeline Questions, Source Analysis |
| **Economics** | 📈 Diagram Questions, Numerical Problems, Correlations |
| **Sociology** | 📖 Case Studies, Real-world Applications |
| **English** | ✍️ Grammar, Essay/Letter/Report Writing, Novel Questions |
| **Hindi** | ✍️ पल्लवन, संक्षेपण, व्याकरण, काव्य सौंदर्य |
| **Sanskrit** | 📜 व्याकरण, अनुवाद, श्लोक भावार्थ |
